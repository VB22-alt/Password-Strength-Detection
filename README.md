#  Password Strength Detection

##  Project Overview
This project uses Machine Learning and Natural Language Processing (NLP) to classify passwords into three categories: **Weak, Medium, and Strong**. It helps evaluate password security by analyzing textual patterns and features extracted from passwords.

##  Features
- Password strength prediction
- Text preprocessing and feature extraction
- TF-IDF Vectorization
- Machine Learning classification
- Easy-to-use Google Colab implementation

##  Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

##  Dataset
The dataset contains passwords labeled according to their strength levels.

##  Workflow
1. Import the dataset
2. Preprocess the password data
3. Convert text into numerical features using TF-IDF
4. Train the Machine Learning model
5. Evaluate model performance
6. Predict password strength

##  Results
The trained model successfully classifies passwords into different strength categories with high accuracy, demonstrating the effectiveness of Machine Learning for password security analysis.

##  How to Run
1. Clone or download this repository.
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Install the required libraries.
4. Run all cells.
